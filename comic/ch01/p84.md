# 第一话「裂空」· P84 / 084

**场景**：同一座风暴平台。红孩儿不服，出手，被一招打回去。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红孩儿扯断腕上的链子，双臂推出一颗巨大的橙色火球，直砸向黑风怪；热浪把空气扭出纹。 | 红孩儿：让开！ |
| 2（中左） | 黑风怪只是侧身让进一团黑气里，斗篷被撕成条；一条铜链钩已经甩出去，在空中拉出长弧；风轮在转。 | 黑风怪：风里，火是客。 |
| 3（中右） | 红孩儿被甩过平台，砸在甲板上，拳上的火断断续续；头发被吹平，脸上全是错愕。 | 旁白：他被自己的火甩了出去。 |
| 4（底部通栏） | 黑风怪站在他上方，鸟喙铁面朝下，风轮还在转，两条链钩垂着；红孩儿单膝跪地、喘着，抬头看他。 | 黑风怪：还打吗？ |

## 绘制备注

- 黑风怪的动作要「省」：侧身、甩链，不多余。他不是在打，是在收东西。
- 第 3 格红孩儿的错愕要盖过愤怒：他从来没遇到过火不管用。
- 无对白气泡与拟声字，文字待上字阶段处理。
