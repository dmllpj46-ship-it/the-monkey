# 第一话「裂空」· P82 / 082

**场景**：黑风星。黑风暴裹住的气体星，补给港挂在浮空平台上。红孩儿单独停靠补给。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红黑小飞船俯冲进布满黑色风暴带的行星；浮空补给平台在风暴里只亮着几个小点，风线朝上抽。 | 旁白：去五彩星，先要补给。 |
| 2（中左） | 驾驶舱：红孩儿瘫在座椅上，一只靴子架在控制台边，颊上火纹被仪表光照亮，一脸不耐烦。 | 红孩儿：加满。别问去哪儿。 |
| 3（中右） | 港口集市：补丁篷布、缆索吊灯、成堆燃料罐；红孩儿压低帽檐，把罐子搬上推车，黑絮从身边刮过。 | 旁白：黑风星的风，是从下往上刮的。 |
| 4（底部通栏） | 回到码头：重型磁力抓钩砸在他的船壳上；一群黑甲、羽披的人从黑风里走出来，手里是锁链与钩刃；红孩儿猛地转身，拳头已经冒火。 | 红孩儿：……谁让你们动我的船？ |

## 绘制备注

- 黑风星的风要「往上」，黑絮与碎屑朝天空走——与后来吹灭火的方向一致。
- 第 4 格他才刚起火，火还没成形；被扣的感觉来自抓钩，不来自打斗。
- 无对白气泡与拟声字，文字待上字阶段处理。
