# 第一话「裂空」· P24 / 024

**场景**：兽星监狱区。成排铁笼、能量栏、滴水管道；高窗外是堆叠的塔城。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 高角俯拍走廊。两侧笼里挤满兽人劳工——狼、牛、鳄、猪，肩上有烙印；走廊尽头一台巡逻机正面走来。 | 旁白：这一层关满了兽人。 |
| 2（中左） | 八戒被推进笼子，跪倒在地；夹钳从栏外抽走，脚踝被扣上镣铐。 | 音效：咔。 |
| 3（中右） | 三个牢友围上来：疤脸狼人、瘦鳄人、老野猪人。狼人朝走廊抬了抬下巴。 | 狼人牢友：这儿是兽星。<br>狼人牢友：以前是我们的，现在归机器。<br>八戒：机器要兽人干什么？<br>鳄人牢友：干活。吃饭得自己挣。 |
| 4（底部通栏） | 越过八戒肩头看出去：巡逻机立在走道上，视镜亮着；更远处是兽星高低错落的塔城和一轮冷月。 | 八戒（低声）：师父……沙师弟…… |

## 绘制备注

- 第 3 格里的「老野猪人」与八戒同为猪形，但皱纹、獠牙磨损与刺青不同；上字时不要让他说话，避免混淆。
- 能量栏在本页偏金黄而非冷青，按牢区照明色温保留。
- 巡逻机在栏外的比例略小（走廊透视），不做修正。
- 无对白气泡与拟声字，文字待上字阶段处理。
