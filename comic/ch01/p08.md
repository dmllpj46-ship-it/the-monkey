# 第一话「裂空」· P08 / 008

**场景**：白色湮灭之光在红孩儿头顶汇聚。红光撕裂天幕，牛魔王与铁扇公主赶到。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 观音抬手，掌心上方凝出一颗纯白的太阳，光把红孩儿的影子压扁在地面；红孩儿仰躺、瞳孔收缩，脸颊火纹黯淡。 | 观音：业火不熄，留你不得。<br>红孩儿：……不、不要—— |
| 2（中左） | 天幕被一道赤红轨迹劈开，碎石与星尘倒卷而上；牛魔王与铁扇公主并肩落在废墟上，巨斧与蕉扇同时顿地，砸出环形裂口。 | 音效：轰——！<br>牛魔王：菩萨——手下留情！ |
| 3（中右） | 两人跪地合掌。牛魔王垂下巨大的角，铁扇公主额头贴地，白光正照在他们身上。 | 铁扇公主：小儿无状，是我们做父母的失教。<br>铁扇公主：愿以全族气运，换他一命。 |
| 4（底部通栏） | 大全景。观音在莲台上俯视，白光悬停未落；牛魔王与铁扇公主跪在红孩儿两侧，红孩儿伏在中间；悟空抱棒坐在断柱上，安静旁观。 | 观音：气运？你们拿什么，替他偿还那些被烧掉的人？<br>牛魔王：……拿我们的命，够不够？ |

## 绘制备注

- 牛魔王的巨斧、熔炉胸核、铁角铜环与铁扇公主的扇冠、扇形肩甲、蕉扇均与定妆稿一致。
- 焦绿色芭蕉扇在本页作为「顿地」的支点出现，扇面偏叶状，可接受。
- 无对白气泡与拟声字，文字待上字阶段处理。
