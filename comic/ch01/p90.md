# 第一话「裂空」· P90 / 090

**场景**：霸主台。火从锁扣里面烧出来。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 全景：哪吒与黑风怪隔着翻卷的黑气对峙；左下前景，红孩儿仍锁在铁环边，低着头看自己的掌心，没人注意他。 | 旁白：两个人在打。第三个人在看自己的手。 |
| 2（中左） | 红孩儿的手部特写：那颗火星贴在锁扣上，火苗不往外冒——细亮的火线顺着链环往里走，像灌进金属里的光。 | 旁白：火没有往外烧。 |
| 3（中右） | 黑风怪的铜框风针眼猛然侧转，指针狂转；鸟喙铁面转过来。他第一次把眼睛从对手身上挪开。 | 黑风怪：……嗯？ |
| 4（底部通栏） | 锁扣炸开，链条落地；红孩儿站起来，两只掌心各一道火；哪吒半转过身，枪还举着；火从画面左右两边亮起，黑风被夹在中间。 | 红孩儿：风里，火是客。<br>红孩儿：客也能烧房子。 |

## 绘制备注

- 第 2 格是整场戏的解法：火不往外烧，往金属里走。风能吹灭火苗，吹不到链子内部。
- 第 3 格黑风怪第一次移开眼神——他意识到真正的威胁在锁上，不在枪上。
- 第 4 格只给位置关系，不给胜负：两人同侧、火从两边亮起、黑气夹在中间。
- 「客也能烧房子」承接 P84 那句「风里，火是客」。
- 无对白气泡与拟声字，文字待上字阶段处理。
