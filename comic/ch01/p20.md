# 第一话「裂空」· P20 / 020

**场景**：回忆。旧天庭之战——碎裂的轨道天宫，天军舰队，火线横穿云海。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 天宫穹顶被金色火线贯穿，碎块与舰队同框；前景废墟上坐着一个少年剪影，背对镜头仰头看。 | 旁白：他记得那一战。 |
| 2（中左） | 悟空与哪吒在半空兵器相撞，金箍棒对火尖枪；风火轮喷出橙色焰环，红绫翻卷。 | 音效：锵——！！ |
| 3（中右） | 悟空对二郎神。三尖两刃刀与金箍棒十字交击，青色与金色电弧炸开；天眼亮起，细犬低扑咬向悟空脚踝。 | 旁白：天庭把能打的，全派下来了。 |
| 4（底部通栏） | 少年剪影举臂，指尖朝向燃烧的天宫；画面边缘整片泛白，像被光洗掉的旧胶片。 | 红孩儿（回忆）：那时候，我想成为他。 |

## 绘制备注

- 第 1、4 格的少年剪影只有轮廓与短发，刻意不给五官：这是记忆里的「当年的自己」。
- 二郎神的天眼在此页偏宝石质感、光芒内敛，与定妆稿的瞄准镜式外放不同，保留。
- 第 2 格金箍棒偏长、几乎横贯画格，读作透视夸张。
- 无对白气泡与拟声字，文字待上字阶段处理。
