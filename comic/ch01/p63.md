# 第一话「裂空」· P63 / 063

**场景**：科研署另一头的车间。钢板墙上是潦草的图，长台上摊满零件，一架用回收线圈拼起来的量子环支在门架上，还没通电。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 车间全貌：红狐女站在钢板墙的图前，用光棒点着一段螺旋草图；六个兽人工程师围着长台，一个举着线圈，一个在记；背后是半装的量子环，线圈全暗着。 | 红狐：船会散，那就不要船。<br>红狐：拆开，送过去，再拼回去。 |
| 2（中左） | 红狐女转身面向镜头，三尾抬起，光棒像教鞭一样举着；镀铬那只眼反着光，表情是「这个数我改不了」。 | 红狐：量子穿越。位置准到能穿结界，误差小于一根头发。<br>旁白：她说这话的时候，没有人笑。 |
| 3（中右） | 八戒的脸：耳朵先垂下去，然后落成一种平的认命；他越过她，眼睛看着那个环。 | 八戒：要多久。<br>红狐：不知道。<br>红狐：快的话，几个月。 |
| 4（底部通栏） | 夜里，他一个人坐在井口坡道边，耙横在膝上，身后是还搭着架子的货船；黑天上一颗很小的五彩星。他什么也没做，就坐着。 | 八戒：……好。<br>旁白：他这辈子最会的事，就是等。<br>旁白：只是这一次，他知道该往哪儿等。 |

## 绘制备注

- 第 2 格的「误差小于一根头发」是她给外行的说法：她是给八戒听的，不是给工程师听的。
- 第 3 格成图里「认命」偏弱、更像平静，按成图定稿，情绪交给第 4 格那个坐着不动的背影。
- 第 4 格是全页的落点：不画计时器、不画日历、不叠字——只用他坐着这件事表达「等」。
- 无对白气泡与拟声字，文字待上字阶段处理。
