# 第一话「裂空」· P54 / 054

**场景**：口袋宇宙内部。同一个虚空，这一次从里面往外开。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 六瓣莲从他头顶开始被从内侧顶开：每一片都像被硬掰的花瓣一样往外翻折，雾气顺着缝隙往外泄；他站在正中，单臂上举，枪横在身前，灰烬般的披风从身上剥落。 | 旁白：莲花是封口的。<br>旁白：从里面开，就是一朵花。 |
| 2（中左） | 枪尖楔进两片花瓣之间的缝；一道橙线从尖上爬出、分叉成网；他的脸被从下方照亮，牙关咬紧，太阳穴上青筋鼓起。 | 音效：咔——<br>红孩儿：……开。 |
| 3（中右） | 从背后看那个裂口：一道竖着的锯齿裂缝，缝里没有光，是真实的黑，还有一股火山灰从外面吹进来。 | 旁白：外面有灰。<br>旁白：灰是从家里来的。 |
| 4（底部通栏） | 他掉出来：整个人穿过灰云下坠，头发与外套被吹得向上翻，枪在身后拖出一线火；下方是火焰山口的熔岩瀑布与炉门堡垒，很高很高的地方，一颗冷白的莲形小星正在缩小。 | 音效：呼——<br>旁白：他出来了。<br>旁白：没有人接他。 |

## 绘制备注

- 第 1 格的「花瓣外翻」要像被从内部顶破的实物，不要画成光效；莲壳是封他的东西，现在被他掰开。
- 第 3 格必须是「黑」而不是「光」——出口的另一边是普通宇宙，这是本页的信息点。
- 第 4 格的莲形冷白小星呼应 P22 第 4 格：同一颗，从这里看是往下掉的。
- 无对白气泡与拟声字，文字待上字阶段处理。
