# 第一话「裂空」· P67 / 067

**场景**：兽星地表。废铁山脊，夜。头顶是智人先锋舰队的矛头阵。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 从废铁山脊仰拍：骨白与石墨灰的舰队铺满天空，矛头阵，最前方一艘母舰最大；舱缝的青光很细，像缝在瓷上的线。山脊上有几个兽人的黑剪影。 | 旁白：天是先暗下来的。 |
| 2（中左） | 黑熊独立在山脊上，大衣被风掀起，一手提黄铜灯、一手拄黑缨长枪，仰头看舰队，下颌绷紧。 | 黑熊：不是机器军团的船。 |
| 3（中右） | 红狐女在他侧后，镀铬瞄准眼收缩，机械手抬起，一根一根数着舰体；狐耳压平。 | 红狐：骨头白，石墨灰，青缝。<br>红狐：智人的制式。 |
| 4（底部通栏） | 极低角度：矛头阵的黑色剪影压在天上，舰首一道极细的青光刚刚亮起；前景兽人士兵很小，都在抬头。 | 红狐：三十二艘。少的那艘是母舰。<br>黑熊：他们回来看仓库了。 |

## 绘制备注

- 智人舰船的语言必须与智人定妆稿一致：骨白 + 石墨灰、几何切面、青缝、一点姜金饰带。要「干净」到和兽星的废铁形成对照——干净本身就是威胁。
- 第 4 格的舰体在成图里更接近竖立的残塔剪影，青光位置是对的，仍读作「舰队压境 + 第一击将发」，按此保留。
- 红狐女成图里夹克敞开露出背心，与定妆稿的闭合夹克有偏差；狐首、义眼、义肢、三尾、毛领均在，身份可辨，记录不改。
- 无对白气泡与拟声字，文字待上字阶段处理。
