# 第一话「裂空」· P33 / 033

**场景**：同一条隧道，劫车打成压制战。积水、蒸汽、被撕开的铁皮。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 帮派被死死压住：兽人贴着废铁不敢抬头，火星从头顶落下，墙面被夹钳捅出一个个洞，一只机械爪从缺口里伸进来；最前面一个年轻兽人抱头缩成一团。 | 旁白：机器的数量是算出来的。<br>红狐：退！退到第二道墙！ |
| 2（中左） | 八戒站起来，走到空地上。姿态毫不漂亮——沉腰、阔步、双手压耙杆——但完全没有情绪。九齿下橙色反重力光把地面的水与灰尘向上托起。 | 八戒：你们数得过来。<br>八戒：俺不用数。 |
| 3（中右） | 耙影横扫：一台机器人从腰部被拆成两截，液压油与冷却液泼成黑弧，冷青视镜裂开、熄灭。 | 音效：咔啦—— |
| 4（底部通栏） | 八戒腾空落下，砸进一堆机械残骸：橙色光在耙下炸开，枪灰与危险黄的碎片横飞，蒸汽柱被压平。远处掩体后，红狐女两只眼睛同时眯起，尾巴绷直。 | 旁白：一耙。<br>红狐（低声）：……头功。 |

## 绘制备注

- 第 2 格是八戒的“力量宣言”格：不摆英雄姿势，重心低、肚子在前，靠体量压人。
- 第 4 格耙齿画成 6–7 齿，正式上字前按定妆的九齿统一。
- 机器人一律不流血；只有油、冷却液、火花。
- 无对白气泡与拟声字，文字待上字阶段处理。
