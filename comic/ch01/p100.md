# 第一话「裂空」· P100 / 100

**场景**：风停了。风一停，星球也没理由再撑。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 黑风怪在死：羽毛从他身上一片片剥下来，化成灰往上飘；背上的四叶轮从轴上脱开，歪着往下掉；铁面具也松了，青色表盘暗下去。他缩在画面中央，比之前小得多，像一件被抽空的东西。头顶留大片空白。 | 黑风怪：……风，停了。 |
| 2（中左） | 极广角，星球本身：地表裂成一块块大陆大的板，缝隙里喷出青光与火，整片平台和铁链往外甩。画面里没有人，只有世界自己在散。 | 旁白：星球也停了。<br>旁白：停完，就散。 |
| 3（中右） | 断掉的码头边上，那条挂着红帆的小铁船：哪吒一枪砍断最后一根锚链，火星四溅；帆已经半张，被倒灌的风扯得啪啪响。红孩儿已经上了船，一手扶着栏，回头看正在塌的中心。 | 哪吒：船。<br>红孩儿：什么？<br>哪吒：你的船，还在锚上。 |
| 4（底部通栏） | 从星球外向下看：小红船红帆全开，被风拽着离开残骸，船头是红孩儿，船尾是哪吒，两人都回头望。身后与脚下，整颗黑风星正碎成无数块，散进黑色的空间。下半格是裂开的星球轮廓，船小而亮，在上方。 | 红孩儿：船是我的。<br>哪吒：锚是我砍的。<br>旁白：他们没回头。碎掉的世界在后面自己走开。 |

## 绘制备注

- 第 1 格是反派唯一一次变小：他不是被击溃，是被抽空。面具先掉，轮子后掉，人还在。
- 第 3 格两人这时都已上船（分镜写的是「哪吒砍链、红孩儿在船上」，成图一致）；船是当初被扣押的那条，红帆有补丁。
- 第 4 格船是贴着星面被风拽出去的，不是垂直脱离——所以「风」到最后一格仍在，只是不再属于他。
- 第一话到这里收束：星球没了，两个人活下来，谁也没说合作这两个字。
- 无对白气泡与拟声字，文字待上字阶段处理。
