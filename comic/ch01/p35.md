# 第一话「裂空」· P35 / 035

**场景**：黑帮地窖更深处。一面废铁墙从中间滑开，露出巨大的地下空穴：黄铜吊灯与改装工作灯、钉在货箱上的手绘隧道图、成卷电缆、关在笼里的机器人核心发着冷青光。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 从两人身后拍：废铁墙在隐藏液压下裂开，红狐女先进，八戒跟在后面低头让过一根横梁，耙还挎在肩上。空穴在他们面前摊开，灯光落在湿石上。 | 红狐：往里。别乱看。<br>旁白：地窖下面还有地窖。 |
| 2（中左） | 空穴尽头，一张货箱拼成的桌后坐着一个巨大的剪影，背对一盏灯，只读得出宽而塌下去的肩膀和两只圆耳朵；胸口一块白，在暗里发亮。 | 旁白：她说的“老大”，不是一个名字。 |
| 3（中右） | 黑熊的脸与胸口从阴影里浮出来：琥珀色小眼，平静、老练，左眼一道竖着的旧疤，灰色口鼻；肩上一条由巡逻机器人头颅串成的绶带，一排冷青视镜还亮着。 | 黑熊：红狐。<br>黑熊：你带回一个会干活的。 |
| 4（底部通栏） | 整个洞窟停下手里的活，所有兽脸转向入口；红狐女向那座背影低头行礼，姿态比她平时低得多；八戒站在外面一步，一只手仍搭在耙上，下颌绷紧。 | 八戒：……这星球上不是只有机器吗。<br>红狐（低声）：那你说给谁听。 |

## 绘制备注

- 黑熊定妆：炭黑熊首、灰白口鼻、胸口骨白色月牙毛斑、左眼竖疤、缺口右耳、沾泥的土褐油布长大衣、肩上串巡逻机器人头颅（冷青视镜）、黑缨长枪。
- 第 3 格那排机器人头颅是战利品，不是装备：不要画成接在线路上的活动装置。
- 第 4 格红狐女的行礼是她在这个组织里的位置，务必画得克制、熟练，不是谄媚。
- 无对白气泡与拟声字，文字待上字阶段处理。
