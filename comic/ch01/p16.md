# 第一话「裂空」· P16 / 016

**场景**：崖边。女娲一句反问，把「找谁」这个问题翻了面。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 女娲近景，掌心托着一枚五色石，笑意很淡；身后银河倒映在她的虹膜里。 | 女娲：你要找哪个师傅呢？ |
| 2（中左） | 悟空抓耳挠腮，眉头拧成一团，完全没听懂。 | 悟空：什么？ |

| 4（底部通栏） | 女娲已经转回身继续洗她的石头；悟空僵在原地，棍子松松垂着。 | 悟空：……这话，什么意思？ |

## 绘制备注

- 第 3 格的残影是刻意保留的多元宇宙回响：三个悟空分别对应「被丢走的那条线」的其他版本，模糊女娲是倒影中的旁观者。
