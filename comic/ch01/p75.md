# 第一话「裂空」· P75 / 075

**场景**：五彩星外层。量子门出口悬在虚空里，脚下是浮空的五色结晶台，五层封印在门切开处向外剥离。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 废铁环门悬在真空中，环心敞着；三个小小的人影踩上浮空的五色结晶台。背景是巨大的条纹行星——青、赤、黄、白、黑，外圈一圈碎石；五色壳片在门切开的地方一层层外翻。 | 旁白：跨越，只用了半步。 |
| 2（中左） | 骨白仿制品把手按进壳片的接缝，胸口六角青核伸出细青线，顺着缝爬进去；它的脸平静得没有变化。 | 仿制品：壳在认我。<br>红狐：……它在给它开门。 |
| 3（中右） | 红狐女蹲在结晶台边缘，镀铬瞄准眼往下扫，三尾被风吹向一侧，毛领竖起。 | 红狐：五层，全开着。<br>红狐：像有人提前来过。 |
| 4（底部通栏） | 八戒踏上五色结晶地面，九齿耙扛在肩上，影子拉得很长；远处地平线上立着织天巨门的残骸，很小。 | 八戒：到了。<br>八戒：这地方，比传说的还空。 |

## 绘制备注

- 封印的「五层」在成图里表现为剥离中的彩色碎块与壳片，读作「层被切开」，按此保留；色彩的五种与 P72 数据图一致。
- 仿制品开门时没有表情变化，也不看人——它是钥匙，不觉得自己在帮谁。
- 无对白气泡与拟声字，文字待上字阶段处理。
