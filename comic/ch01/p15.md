# 第一话「裂空」· P15 / 015

**场景**：崖边。悟空叩拜，说出取经船出事的经过。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 悟空整只趴伏在地，额头几乎贴到石面，金箍棒横放在身旁，红披风散了一地；女娲立在上方，蛇尾盘在身后，神情看不出喜怒。 | 悟空：弟子孙悟空，拜见女娲娘娘。 |
| 2（中左） | 悟空抬头，咬紧牙，眼里是不肯认输的狠劲。 | 悟空：我师父和两个兄弟，被火教的红孩儿撕开时空，扔进了宇宙深处。 |
| 3（中右） | 女娲的手垂在身侧，指尖绕着一段星光线，慢慢打圈。 | 女娲：（不语） |
| 4（底部通栏） | 大远景。伏地的猴子与立着的女神，背后是整条七彩银河。 | 悟空：求娘娘指一条路。哪怕要我把这条命押上。 |

## 绘制备注

- 悟空是完整的趴伏叩拜，不是单膝；金箍棒横放在地，符合「放下兵器」。
- 第 3 格女娲沉默，是这段的节拍点，上字阶段不要加台词。
- 无对白气泡与拟声字，文字待上字阶段处理。
