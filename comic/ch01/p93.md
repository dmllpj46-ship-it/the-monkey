# 第一话「裂空」· P93 / 093

**场景**：霸主台。风不接火，也不让火过去。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红孩儿沉腰，双手把整团火推出去，直冲黑风怪；火球在两人之间被黑气拦停在半空，进不去，也掉不下来。黑风怪一动没动。 | 旁白：火全推出去。风不接，也不让。 |
| 2（中左） | 高角度：哪吒从上方压下来，枪尖指向鸟喙铁面，双轮全开，红绫在身后笔直朝上。 | 黑风怪：急的人，先露背。 |
| 3（中右） | 黑风怪往自己的黑气里退了一步；一条带钩的链子从雾里抽出来，绕住哪吒的脚踝，把他横着甩向红孩儿。拖影、火星。 | 旁白：链子从黑气里出来，绕住脚踝——把他甩向另一个人。 |
| 4（底部通栏） | 红孩儿一脚踢断甩过来的链子，两个人一起摔在甲板上，断链和火星四散；并排趴着，互相瞪。 | 红孩儿：……别碰我。<br>哪吒：是你先碰的我。 |

## 绘制备注

- 第 1 格成图是火球被黑气拦停在半空，没有画成被拽偏；旁白按成图改成「不接，也不让」。
- 第 1 格红孩儿手里是他的火尖枪（设定武器），从被扣的船上摸回来的，不给台词指认。
- 第 3 格是全页因果：链子不是打人，是把人当武器扔出去，让两个人撞在一起。
- 无对白气泡与拟声字，文字待上字阶段处理。
