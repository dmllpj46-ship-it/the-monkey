# 第一话「裂空」· P62 / 062

**场景**：同一间科研署。星图锁定之后，球体开始报警——它没有替他高兴的模块。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 球面上的亮带由冷青翻成琥珀，一格一格地亮过去；栈桥上红狐女的耳朵压平，八戒回头。 | 智能之母：警告。 |
| 2（中左） | 全息投影：五色星被一层五瓣的壳包住；他们那艘货船的模型靠上去，轮廓在壳面上拉花、碎开。 | 智能之母：目标行星外围存在结界。<br>智能之母：五色封印，非授权者不得通行。 |
| 3（中右） | 八戒的侧脸，牙关咬紧，獠牙压着下唇，眼睛没离开投影。 | 八戒：我的船呢。<br>智能之母：已模拟。接触后第十一秒解体。 |
| 4（底部通栏） | 全息拉到全尺寸：壳的直径与那艘小船的比例悬殊到荒谬；两人一左一右站在投影里，都小，都静止。 | 红狐：……那颗星比我们想的大。<br>八戒：不是它大。是我们小。 |

## 绘制备注

- 第 1 格的琥珀是这套机械唯一的「情绪」：不要给它脸部变化或手势，只给灯色。
- 第 3 格成图里没有拳头砸栏，只有咬紧的侧脸；按成图定稿，力度交给台词「已模拟。接触后第十一秒解体」。
- 第 4 格的比例是全页信息点：壳要比船大得多，但星本身只占中心一小点。
- 无对白气泡与拟声字，文字待上字阶段处理。
