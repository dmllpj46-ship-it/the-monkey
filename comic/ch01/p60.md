# 第一话「裂空」· P60 / 060

**场景**：退潮的废墟滩。哪吒听完，笑了一下，然后走了。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 面部特写，冷笑：嘴角一侧提起来，眼睛眯起、带着毫不掩饰的兴致，露了一点牙；雨水从下颌一颗颗往下滴，背景里云层还被光环照着。 | 哪吒：巧了。 |
| 2（中左） | 脚部特写：两只风火轮的轮机同时点火，橙色尾焰往下压进浅水，蒸起一圈白汽与水环。 | 哪吒：我正缺个对手。 |
| 3（中右） | 他挑起枪，笔直立在空中朝天上行了个礼；人已经离地，红绫与腰带被尾焰吹得横飞，下巴抬着，笑还没收。 | 观音：带回来。 |
| 4（底部通栏） | 人已经走了：一道橙色的火线穿过云底；下面的滩地在冒汽，浅水被震出一圈圈涟漪；法相散得只剩云里几点网点。 | 哪吒（远去）：活的？<br>观音：活的。<br>哪吒（远去）：……那我尽量。 |

## 绘制备注

- 第 1 格的「冷笑」是这三页的落点，第一版成图只有冷峻、读不出笑，重出一次才拿到；这类表情偏差属于必改项。
- 第 3 格是「领命」的全部信息：他不说话，只行礼、起跳。
- 第 4 格成图里法相已经完全散尽，没有脚本写的「残影网点」；按成图定稿，收尾更干净。
- 观音要活的——与 P06「杀念一起，火就烧到自己身上」同一条线；不要写成纯粹的雇佣关系。
- 无对白气泡与拟声字，文字待上字阶段处理。
