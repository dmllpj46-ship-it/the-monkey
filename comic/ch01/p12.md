# 第一话「裂空」· P12 / 012

**场景**：五彩石星。悟空找到传说中的星球，也找到了空无一人的织天殿。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 狭窄的复古驾驶舱，悟空瘫在驾驶座上，脚翘在控制台边，一手扶舵，金色仪表光打在脸上，舷窗外星流拉成线。 | 悟空：五彩石星……牛鼻子，你要是骗我—— |
| 2（中左） | 船外大远镜。一艘带红帆的小船靠近一颗巨大的五色条纹行星，行星外环悬着一圈碎石。 | 旁白：它真的存在。 |
| 3（中右） | 悟空踩上五色结晶地面，风掀起披风；前方是一座巨大的「织机」与「天门」缝合而成的遗迹，空无一人。 | 悟空：女娲——！我找你有事！ |
| 4（底部通栏） | 巨殿内部。悟空在画面中央小得像一粒尘，两侧石柱高不见顶；尽头的基座亮着，座位是空的。 | 旁白：织天的机器还在转。座位空着。<br>悟空：……人呢？ |

## 绘制备注

- 金箍在本页看上去完好，裂缝在整页缩放下不可辨；后续特写仍需保留裂纹。
- 驾驶舱为本作首次出现的内部场景（金色复古科幻 + 木质与黄铜质感），可作为后续飞船内景的基准。
- 五色星球的条带为青、赤、黄、白、黑；与女娲身上的五色石同源。
- 无对白气泡与拟声字，文字待上字阶段处理。
