# 第一话「裂空」· P81 / 081

**场景**：兽星地下大厅。量子门重开，黑熊迎接悟空。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 门心炸亮，四人依次走出；满洞窟的兽人同时转过头，黑熊从人群里大步迎上来，大衣甩开。 | 旁白：洞窟里很久没有这么吵过。 |
| 2（中左） | 黑熊与悟空面对面站着，熊高出他整整一头；一个持黑缨长枪，一个拄金箍棒，两人都咧着嘴。 | 黑熊：你就是那只猴子。<br>悟空：你是那头熊。 |
| 3（中右） | 黑熊面部特写：双耳朝前立起，琥珀色的眼睛发亮，带疤的口鼻松开——那种他很少露出来的真笑。 | 黑熊：……欢迎回家。 |
| 4（底部通栏） | 全厅：几百个兽人举起工具、长枪与黄铜灯；悟空站在一只货箱上让他们看得见，黑熊立在他肩侧，八戒与红狐女在画面边缘。 | 旁白：他说的不是「欢迎回来」。<br>旁白：是「回家」。 |

## 绘制备注

- 第 2 格成图是两人并肩而立、互相打量，不是掰手腕；「第一次照面」的读法仍成立，按此保留。
- 第 3 格的笑要收着：嘴角动、眼睛亮，但别咧嘴大笑——他不是热情的熊，是终于等到了。
- 全页不出现智能之母；这一幕是人的。
- 无对白气泡与拟声字，文字待上字阶段处理。
