# 第一话「裂空」· P44 / 044

**场景**：智能之母内部，机房已被抵抗军改作资料库。地面一圈应急红灯仍在，一小片视镜墙被重新供电，几百枚冷青视镜在黑暗弧壁上弱弱地亮。八戒与红狐女站在一台复原的控制台前。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 控制台升起一道冷蓝光锥，在黑暗球腔里铺成层层剖面全息：地表矿场之下，一圈又一圈的实验室、笼舍、手术厅、育幼舱。两人小得可怜。 | 红狐：它死了，可它没忘。<br>旁白：他们把这台机器叫醒，只为了问一句“我是谁”。 |
| 2（中左） | 全息特写：一枚徽记缓慢转动——圆环里是一颗兽首骨骸与一具上升的量尺，纯线条，没有任何文字。 | 八戒：这是它的名字？<br>红狐：这是这座地方的名字。 |
| 3（中右） | 重建画面：一排穿骨白紧身衣的智人拿着数据板，冷静地站在笼舍外；笼里猴、猪、熊、狐戴着细环颈圈与电极；一名智人俯身，用指挥杆的尖端碰了碰一头小熊的头。 | 旁白：科研站。编号不明。<br>旁白：课题只有一行——提升受试动物的智慧。 |

## 绘制备注

- 智人定妆见 `assets/characters/sapiens.png`：光头无眉、石墨耳甲配冷青缝、鬓角青色电路线、颅后悬浮分段数据环、骨白配石墨紧身甲、姜金胸带与六角青色胸核。
- 第 2 格徽记（圆环 + 兽首骨骸 + 量尺）是这座科研站的旧徽记；P47 的铜牌徽记由它演变，两版需在设定阶段统一。
- 第 3 格的智人一律不画怒容、不画虐待：他们礼貌、干净、把动物当数据——这才是这一格的恐怖。
- 无对白气泡与拟声字，文字待上字阶段处理。
