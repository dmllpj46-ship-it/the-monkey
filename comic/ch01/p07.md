# 第一话「裂空」· P07 / 007

**场景**：红孩儿抢先出手，火枪如雨。观音抬手，火被当成流水拨开。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 大广角。红孩儿腾身，数十支火焰枪影铺满天空，全部射向莲台上的观音；光环如薄壳，枪影在壳外炸开成环状火雨。 | 红孩儿：装神弄鬼——去死！<br>音效：咻咻咻—— |
| 2（中左） | 观音特写，右手竖掌，火枪贴着掌心滑开，绕着她旋成几道橙色水纹，衣袂不扬。 | 观音：风来。<br>观音：定。 |
| 3（中右） | 一只白玉手掌按落，红孩儿被砸进地面，石板呈蛛网炸裂，火尖枪从中折断，碎铁与火星四散。 | 音效：咚——！<br>音效：铮。 |
| 4（底部通栏） | 全景。红孩儿被一朵半透明的莲花光印压在地面，四肢撑地挣扎；莲台悬于上空，悟空拄着金箍棒站在左侧仰望。 | 观音：你的火，烧不动因果。<br>红孩儿：放开我……！ |

## 绘制备注

- 火尖枪在本页折断，第 8–9 页红孩儿不再持枪，连续性以此为准。
- 金箍棒在第 5 页脱手后于本页重新出现在悟空手边，可解释为战斗间隙取回；若后续重绘，可补一格「棒自远处飞回」。
- 第 3 格的落差感（一击压制）是本页的情绪核心，上字时可放大冲击拟声。
- 无对白气泡与拟声字，文字待上字阶段处理。
