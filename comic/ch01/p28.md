# 第一话「裂空」· P28 / 028

**场景**：废料摊后的密室。货箱当桌，吊灯低垂，蒸汽管贴着墙走。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红狐女把路线全息摊在货箱上：红色线路穿过隧道网，一枚货车标记在闪。八戒俯身看，怀疑。 | 红狐：明天夜里，三号井，一支车队。 |
| 2（中左） | 机械手指点住其中一只货柜；标签位置是一整块涂黑，没有任何可读信息。 | 八戒：抢什么。<br>红狐：你不用知道。 |
| 3（中右） | 八戒面部特写。眉压低，獠牙反光，眼睛眯起，明显不接受。 | 八戒：不知道抢什么，我就不去。 |
| 4（底部通栏） | 八戒转身走进人群，抬手拒绝；红狐女坐在箱上没动，尾巴慢慢卷起。 | 红狐（低声）：你会回来的。<br>旁白：她没有追。 |

## 绘制备注

- 全息里的黑块是剧情信息，上字时不要把货柜内容补出来。
- 第 1、4 格她的机械臂被画在右侧（与定妆的左侧相反），按镜像保留，视为同一人。
- 案上货箱、投影器为临时道具。
- 无对白气泡与拟声字，文字待上字阶段处理。
