# 第一话「裂空」· P86 / 086

**场景**：黑风星轨道外。黑风暴从星面往上刮，补给港挂在云顶之上。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 大远景：气体星被黑色风暴带整圈裹住，黑絮与碎屑从星面往上刮进太空；云顶之上挂着一串浮空平台，缆索、篷布、吊灯；一道橙色的火线从星海尽头插进来。 | 旁白：黑风星的风，是从下往上刮的。 |
| 2（中左） | 哪吒踩着风火轮悬在风暴边缘，红绫被上升气流吹得笔直朝上，轮下的橙焰被梳成一条横线；他低头看，神情冷淡。 | 哪吒：观音要活的。 |
| 3（中右） | 下方平台上：红帆小船被磁力抓钩与粗链钉死，船壳上刮出链痕；黑甲守卫提着钩索围在四周，灯笼照着黑气。 | 旁白：船被扣了。帆还在——人就不一定了。 |
| 4（底部通栏） | 哪吒面部的近景，火光从下方照上来，眼睛压着，嘴角一侧提了一点。黑风与撕裂的风絮从背后刮过。 | 哪吒：……找到你了。 |

## 绘制备注

- 第 1 格的风必须往上走：黑絮、碎屑、缆线全部朝天空飘，这是这一页的物理前提。
- 第 3 格的船就是 P76 那艘红帆小船：帆还在，桅杆歪着，船壳被链痕刮出白茬。
- 第 4 格只给半边脸和一点冷笑：他找到了，但还没打算费力。
- 无对白气泡与拟声字，文字待上字阶段处理。
