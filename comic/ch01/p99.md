# 第一话「裂空」· P99 / 099

**场景**：一口张嘴的风，一杆捅进去的枪。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 仰视全景：黑风怪悬在裂开的井底正中，背上的四叶轮整个转向前方，轮心的进气口像一张黑洞似的嘴，把周围的钢板、铁链和青光一起卷成螺旋往里吸。画面两下角是两个小小的黑影。 | 黑风怪：都进来。<br>旁白：风轮转过来，口张开了。 |
| 2（中左） | 低角度：红孩儿腾空，双掌前推，一道笔直的白橙色火柱从他掌心射出去，正打进轮心的口子。整个人压在这道火上，红带朝后扯，牙关咬死。 | 红孩儿：张嘴了。 |
| 3（中右） | 近景：哪吒贴着铁面冲上去，长枪从面具和头盔的接缝处往上捅，一颗铆钉当场崩飞；风火轮的火在脚下炸开。他的脸是静的，眼睛锁在接缝上。 | 哪吒：就是现在。 |
| 4（底部通栏） | 结算：火已经钻进风轮里，黑风怪整个身体向后仰折，面具沿接缝裂开，螺旋的风开始倒转，青光被那道火吸着往回卷。两个小孩并排站在下面，一个裹着橙火，一个踩着青橙两色的轮光，谁也不看谁。 | 旁白：火顺着风，一直往里走。<br>黑风怪：……不。 |

## 绘制备注

- 两次攻击是同时的，不是接力：火先到，枪在同一瞬间卡住接缝，缺一个都不成立。画面上要能看出时间是一致的。
- 第 3 格分镜写的是六臂，成图只画出双臂握枪——按一版过，接受；六臂不是这一击的关键，接缝才是。
- 第 4 格的火进了喙与轮之间的腔体，不是单独进了轮口；旁白因此写「往里走」而不写具体位置。
- 星球仍在崩：这一格的背景必须全是浮起来的碎块。
- 无对白气泡与拟声字，文字待上字阶段处理。
