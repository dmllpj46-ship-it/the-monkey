# 第一话「裂空」· P83 / 083

**场景**：黑风怪的风暴平台。红孩儿被押到霸主面前，第一次发现自己的火压不住这里。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红孩儿被押过狂风平台，走向尽头的黑风怪；斗篷下摆碎成黑气，背后铜风轮慢慢转着；两侧是黑甲羽披的手下。 | 旁白：他们把他带到风暴中央。 |
| 2（中左） | 黑风怪的面部特写：长弯鸟喙铁面俯下来，铜框风针义眼里的指针在转，冷青绿的光打在铁上。 | 黑风怪：火教的小崽子。 |
| 3（中右） | 红孩儿手腕上锁着链子，掌心托起一团亮橙的火；黑风把火苗吹得横过去，压成一根细线；他火色的眼睛睁大了。 | 红孩儿：知道还敢扣？ |
| 4（底部通栏） | 黑风怪抬起一只枯长的手，黑气从斗篷里涌出；红孩儿手里最后一点火星灭掉，他整个人向后一缩，脸上第一次是惊。 | 旁白：他的火，点着了，又被吹灭。<br>红孩儿：……什么？ |

## 绘制备注

- 黑风怪全程不露脸、不着急；他的压迫感来自「火在他面前变小」。
- 火烧不起来的因果要一眼看懂：不是被水浇灭，是被风压熄——火苗先横过去，再细下去。
- 无对白气泡与拟声字，文字待上字阶段处理。
