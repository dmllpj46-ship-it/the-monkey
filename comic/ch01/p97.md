# 第一话「裂空」· P97 / 097

**场景**：他不打。他把整颗星球当燃料。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 黑风怪的侧脸特写几乎填满整格：铆钉铁盔、一只往下弯的长喙、铜环垂在盔侧，背上的四叶铜轮只露出半边。背景全白，只有几片黑絮在飘。 | 黑风怪：客人不走，主人就把房子卖了。 |
| 2（中左） | 从井底往上看：四叶轮的中心张开成一个黑洞似的进气口，星核的青光被抽成上千根发丝一样的细线，整束往上灌进那个口子里。 | 旁白：星核被抽成一根光柱，往上走。 |
| 3（中右） | 面具的另一个角度，特写：青色表盘一样的眼窝整个亮起来，光从喙缝里往外泄，铁面的接缝处也被撑得发白。 | 红孩儿：他在喝。<br>哪吒：喝完呢。<br>红孩儿：喝完就没星了。 |
| 4（底部通栏） | 井口已经被彻底掀开：两个小孩站在一块翘起来的断裂平台上，被抛到星球表面之上的开放天空里；无数平台、链条、碎石从他们身边往上升，黑天被青色闪电劈开，脚下远处是正在开裂的地表。 | 旁白：脚下裂开。整块地开始往上飞。<br>黑风怪：风会停。<br>黑风怪：你们会留在原地。 |

## 绘制备注

- 第 3 格的眼窝是「表盘」不是「眼睛」，指针状的光纹可以保留；这是全篇他唯一一次露出「满足」。
- 星球崩解从这一页开始：之后所有场景的地面都必须是碎的、翘的、浮的，不能再有平整甲板。
- 第 4 格的两个人在同一块板上，但仍然各站一边，中间空着。
- 无对白气泡与拟声字，文字待上字阶段处理。
