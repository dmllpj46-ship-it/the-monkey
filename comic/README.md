# Comic pages

Finished pages go here as `chNN/pNN.png` (2-digit chapter, 2-digit page), e.g. `ch01/p01.png`.

Follow `assets/characters/design-bible.md` for every character in frame. Page notes (deviations, panel breakdown) can sit next to the images as `pNN.md`.
