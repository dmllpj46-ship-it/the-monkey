# 第二话「同囚」· P111 / 111

**场景**：玉白航向的尽头。红帆小船落进无尘星。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 高空远景：红帆小船穿过薄雾下降，白树干没入云里；船后那道玉白细线在天边淡下去。下方一条石板路笔直穿过森林。 | 旁白：航向到这里就断了。 |
| 2（中左） | 船贴着六边形石路悬停，补丁红帆松着。哪吒先踩下来，风火轮的光暗下去；红孩儿已经跳到前面，肩上散着火星，两手空着。 | 哪吒：分头找。 |
| 3（中右） | 哪吒指向石板路，下命令。红孩儿已经背过身，朝相反方向走进树干之间，抬手摆了摆，没回头。 | 哪吒：找到了别动手。<br>红孩儿：看心情。<br>哪吒：红孩儿。<br>红孩儿：……知道了。 |
| 4（底部通栏） | 全景：两人一左一右分开，船像搁浅在路中间；路两边的蓝灰石头全部慢慢转过来，朝着两个新来的人。 | 无对白。 |

## 绘制备注

- 这一页只做两件事：把两个人放下船、让他们分开。不交代任务，不解释观音，台词越少越好。
- 第 2、3 格哪吒的长枪没画出来，接受：可以当作在背上或船里，这一页他用不上枪。
- 第 4 格两人都走在石板路上、只是分向左右，而不是一个入林一个沿路；接受，分头仍然成立，路线不同。
- 第 1 格的玉白航向已经在船后淡去，读作「航线到此为止」，与剧情一致。
- 石头转头看新来的人，是星球的下意识动作；不要画成敌意。
- 无对白气泡与拟声字，文字待上字阶段处理。
