# 第二话「同囚」· P108 / 108

**场景**：两只手先碰上。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 唐僧与沙僧面对面坐在空地上，月牙铲横在沙僧脚边。唐僧伸出手掌，掌心向上，等着。 | 唐僧：借我一只手。<br>沙僧：做什么？<br>唐僧：跟它说话。 |
| 2（中左） | 手部特写：一只白而细的手，一只蓝灰而粗大的手，握在一起。干净、慢，没有用力。 | 旁白：他先教它，什么叫"碰"。 |
| 3（中右） | 石头照着做：三块大石头挤在一起，石面真正相触，接缝里窜出冷青色的细线，细灰从缝里升起来。 | 唐僧：对。就是这样。<br>沙僧：……它学会了。 |
| 4（底部通栏） | 全景：整片空地的石头彼此扣合、连成一片，铺成一只摊开在石地上的巨大手掌；两个人坐在掌心，很小。 | 沙僧：它在回话。<br>唐僧：它说，它在这里。 |

## 绘制备注

- 这是整条语言线的转折点：星球的第一个"词"不是声音，是接触。
- 第 2 格是全页的情感锚：两只手的差距（颜色、粗细、干净程度）必须保留，不许画成一样的手。
- 第 3 格是星球第一次自己越过"不碰"的规矩——因为有人先做给它看。
- 第 4 格拼出的是一只摊开的手，不是十指相扣；这个偏差保留，改读作"星球第一次伸出的手"，比相扣更合这一页的情绪。
- 从此以后，石头可以相触；这是后面所有"说话"的前提，别忘了。
- 无对白气泡与拟声字，文字待上字阶段处理。
