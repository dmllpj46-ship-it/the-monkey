# 第二话「同囚」· P114 / 114

**场景**：哪吒赶到。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 红孩儿从石墙里撞出来，一道火弧把整排石兵掀开，碎石乱飞；缺口后面只剩唐僧与沙僧。 | 红孩儿：让开！ |
| 2（中左） | 沙僧横铲接住，深铜色的铲刃锁住燃烧的掌心，火星四溅；地上的石兵伸手抓住红孩儿的靴子；唐僧在沙僧身后，手掌抬起。 | 沙僧：不让。 |
| 3（中右） | 特写：红孩儿腾空，掌火推向唐僧的脸；一杆细枪从画面右侧切进来，枪尖插在掌心与脸之间，各差一指。红披带与前臂入画。 | 哪吒：住手！ |
| 4（底部通栏） | 全景：哪吒落在两人中间，风火轮在石地上烧出两圈黑印，枪横在中间；石兵全部停在半路；沙僧仍举着铲，唐僧放下手。 | 红孩儿：你来干什么。<br>哪吒：观音让我们来找他。不是来烧他。<br>哪吒：这星球是活的。你烧的是它的手。 |

## 绘制备注

- 这一页的节奏是「差一点」：火到脸前，枪到火前。哪吒不是打赢了红孩儿，是把这一下截住了。
- 第 1 格远景多出一个红衣小人影（模型把红孩儿重复画了一次）。成页保留，上字/裁切阶段压掉；不要当作第二个角色。
- 第 3 格枪尖比「停在掌心与脸之间」更贴唐僧的脸，接受，读作「从侧后插入、擦着脸停住」。
- 第 4 格哪吒的枪更接近突刺位而不是横挡，接受，因为他落地时红孩儿还在往前冲。
- 「这星球是活的」是哪吒看见焦石与暗掉的青缝之后说的，不是听唐僧解释的。这是误会开始解开的一刻。
- 无对白气泡与拟声字，文字待上字阶段处理。
