# 第二话「同囚」· P110 / 110

**场景**：天亮。一条路自己铺到天边。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 晨光里，唐僧跪在六边形石地上，用手指在灰里画星图：大小不一的圆点、点与点之间的细线，没有字，没有数字。沙僧拄铲站在后面。四周的蓝灰石头全部倾斜，朝着这张图。 | 唐僧：它没有词。<br>唐僧：但它有位置。 |
| 2（中左） | 低角度特写：指尖按住图上的一个点；正上方一块石头悬着，内里的纹路亮起冷青色的一圈，像睁眼。 | 沙僧：指哪儿？ |
| 3（中右） | 石头落在那个点上；冷青的细线从石头底下窜出去，穿过整片石地。远处，一列石头次第立起，一块接一块，笔直排向天边。 | 唐僧：这儿。 |
| 4（底部通栏） | 清晨大远景：两个很小的身影并肩走在石头排成的路上，路笔直插进薄雾里的白树干之间；路两边是立着的石子，像里程碑。高处的淡色天空上，有一道极细的玉白光横过半个天。 | 沙僧：几个？<br>唐僧：两个。都很烫。 |

## 绘制备注

- 这是对话的第四层：语法是"位置"，不是声音。放一块石头在某个点上，就是一句话。
- 第 3 格石头是立着排成一线，不是平铺成路面——读作里程碑，不是铺路；旁白照这个写。
- 第 4 格那道玉白细线是观音留下的航向，不是装饰，也不是流星；天边没有第二道光，"两个"只走台词。
- "两个。都很烫。"是下一段（哪吒与红孩儿进山）的钩子；星球数得到两个人，唐僧读得出他们的温度。
- 全页没有一次胜利的姿态：他们只是终于能问路了。
- 无对白气泡与拟声字，文字待上字阶段处理。
