# 第二话「同囚」· P101 / 101

**场景**：红帆小船漂在碎星之间。星球没了，谁也没赢。

## 分镜

| 格 | 画面 | 台词 / 音效 |
| --- | --- | --- |
| 1（顶部通栏） | 极广角：补丁红帆的小铁船侧浮在碎星带里，帆半张着；背景是被拆开的星球外壳，巨大、残破，裂缝里还渗着青色，四周悬着平台残块、钢板和断链。船很小。 | 旁白：星球只剩一半。船还在。 |
| 2（中左） | 甲板中景：红孩儿双脚分开站定，一只手指着哪吒，另一只手上托着一团拳头大的橙色火，咧嘴抬下巴，眼里全是挑衅。身后是被扯烂的帆绳。 | 红孩儿：刚才不算。<br>哪吒：什么不算。<br>红孩儿：你救过我一次。我不算欠你的——谁厉害，得打一遍。 |
| 3（中右） | 甲板中景：哪吒坐在船尾栏杆上，一只手搭着舵柄，长枪横在膝上。他只睁开一只眼，嘴角慢慢翘起来——还没站起来，但已经答应了。脚跟的风火轮懒懒地燃着小火。 | 哪吒：行。<br>哪吒：船别打沉。 |
| 4（底部通栏） | 低角度横过甲板：两人已经拉开架势，相隔十步。红孩儿压低身子，双掌张开，火顺着手臂往上爬；哪吒侧身站着，枪尖平举，轮下的火全开。两人之间是散落的绳子、木箱和半截帆，栏杆外面就是黑天和慢慢翻滚的残骸。 | 红孩儿：船是我的。<br>哪吒：那就更别打沉。 |

## 绘制备注

- 红孩儿的长枪留在霸主台上了，没捡回来——所以这一场他用掌。
- 船必须是 P100 那一条：铆接铁壳、单桅、补丁红帆；这场决斗从头到尾不许把船打沉，也不能让它看起来像另一条船。
- 两人各站一边，中间那块甲板空着，和第二话的标题一样：同一条船，不同的牢。
- 无对白气泡与拟声字，文字待上字阶段处理。
