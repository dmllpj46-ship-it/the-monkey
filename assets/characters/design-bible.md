# Character Design Bible

This file is the canon. Every future page, cover or promo image must match the sheets in this folder. When a page and this file disagree, this file wins.

## Locked art direction

Reuse this block verbatim in every image prompt:

> professional Japanese shonen sci-fi manga illustration, crisp black ink linework, cel shading with screentone dot patterns, limited bold palette, 1990s-2000s manga poster polish, pale warm-gray paper, halftone starfield

Reference-sheet layout (for new characters only): vertical sheet, full-body three-quarter view on the left, large head-and-shoulders portrait on the right, thin ink border frame, faint halftone starfield background, no text or labels.

### 智人 — `sapiens.png`

- **Role**: 消失的建造者种族。兽星原本是他们的科研站，课题是「提升受试动物的智慧」；实验成功后他们整体撤离，只给智能之母留下一条没人收回的指令。唐僧一族的同型。
- **Build**: 成年人类体型，约 1.8 m，瘦直、比例精确；无尾、无爪、无毛、无角；五指细长、指甲平；站姿节省，常背手或持器。
- **Head / face**: 苍白皮肤，光头无眉，颅面光滑；高阔额头；大而静的黑眼，虹膜里一圈青色反光；小直鼻、薄唇、礼貌的漠然；耳朵不可见——两侧是石墨耳甲，带一道冷青细缝；鬓角到下颌有两三条发光的青色电路细线。
- **Headgear**: 颅后悬浮的分段数据环（骨白 + 石墨），一个青色标记灯；是接口，不是宗教光环。
- **Costume**: 骨白配石墨拼接的一体紧身甲，高立领密封，无明显缝线；胸前与大腿外侧一条姜金饰带（唯一暖色）；胸口六角青色数据核；腕踝露出深色内衬；无缝磁吸靴与裤腿一体；手套关节有细青线。
- **Props**: 右手细指挥杆——骨白短杆、顶端悬浮青环，用于下达指令；左前臂旁悬一块半透明浅蓝数据板，只有网格线，无可读内容。
- **Palette**: 骨白、石墨灰、姜金、青、苍白肤色。
- **Never change**: 光头无眉、石墨耳甲与青缝、鬓角青色电路线、颅后悬浮数据环、姜金胸带、六角青色胸核、指挥杆。
- Note: 智人只出现在档案回放与全息里（P44、P45），不进入现在时。画他们时禁止怒容与虐待姿态——他们的可怕在于干净、礼貌、把动物当数据。

### 智能之母 — `mother-mind.png`（非人形锚点）

- **Role**: 兽星的统治者。不是机器人，是一整颗星球的运算核心；巡逻机器人与机械军团都是它的手脚。
- **Form**: 山岳级球体，坐落在地底空穴里，由暗钢支塔与电弧夹钳托住；赤道一圈完整检修栈桥与吊臂。
- **Hull**: 枪灰铆接装甲板拼成球壳，散热百叶、管束、线缆桥架密布；若干板块画危险黄斜带；接缝渗锈，下半球挂着油烟与泥痕。
- **Eyes**: 球面密集成千上万枚单缝冷青视镜——与巡逻机器人同一套视觉语言，像复眼一样排布；正中央一道巨大的横向主视镜，狭长、无嘴、无人脸。
- **Feeding**: 球体底部一束粗如隧道的脐带主干线垂落，插进下方发橙光的能源井；井口有热浪与瀑布状冷却水。
- **Scale cues**: 吊装平台、索桥吊篮、栈桥上蚂蚁般的机器单位——用来衬托球体之大。
- **Palette**: 枪灰、油黑、危险黄、冷青、锈橙、炉光橙。
- **Never change**: 球形 + 密集单缝冷青视镜 + 中央一道横向主视镜 + 危险黄斜带 + 底部脐带管线接入发光能源井。
- Note: 本稿是 1536x1024 横版场景锚点，不是角色定妆版式；作页面参考时说明「这是智能之母的外形与尺度基准」。它被破坏时按顺序失能：先能源井（P40，视镜成片转暗）→ 后主视镜与干线缆（P42，全灭，只剩应急红灯）。

## Using the anchors

`thumbs/<slug>.jpg` are 4:5 web crops of the right-hand portrait on each sheet, used by the reading site. They are derived, never canon — regenerate them if a sheet changes.

1. **Same character, new page**: pass the matching sheet to ImageGen as a reference image and state "the first image is the identity and costume reference; keep face, hair, silhouette, costume and palette unchanged". Restate the locked art direction.
2. **Multi-character panel**: one reference per character, labeled by order. Keep each character's never-change list in the prompt.
3. **New characters**: generate a sheet in the same layout, add them here, then they become canon.
4. **One pass per asset.** No regeneration loops. If the result deviates, record the deviation in the page notes and move on.
