This file is the canon. Every future page, cover or promo image must match the sheets in this folder. When a page and this file disagree, this file wins.

### 智人 — `sapiens.png`

- **Role**: 消失的建造者种族。兽星原本是他们的科研站，课题是「提升受试动物的智慧」；实验成功后他们整体撤离，只给智能之母留下一条没人收回的指令。唐僧一族的同型。
- **Build**: 成年人类体型，约 1.8 m，瘦直、比例精确；无尾、无爪、无毛、无角；五指细长、指甲平；站姿节省，常背手或持器。
- **Head / face**: 苍白皮肤，光头无眉，颅面光滑；高阔额头；大而静的黑眼，虹膜里一圈青色反光；小直鼻、薄唇、礼貌的漠然；耳朵不可见——两侧是石墨耳甲，带一道冷青细缝；鬓角到下颌有两三条发光的青色电路细线。
- **Headgear**: 颅后悬浮的分段数据环（骨白 + 石墨），一个青色标记灯；是接口，不是宗教光环。
- **Costume**: 骨白配石墨拼接的一体紧身甲，高立领密封，无明显缝线；胸前与大腿外侧一条姜金饰带（唯一暖色）；胸口六角青色数据核；腕踝露出深色内衬；无缝磁吸靴与裤腿一体；手套关节有细青线。
- **Props**: 右手细指挥杆——骨白短杆、顶端悬浮青环，用于下达指令；左前臂旁悬一块半透明浅蓝数据板，只有网格线，无可读内容。

- **Never change**: 光头无眉、石墨耳甲与青缝、鬓角青色电路线、颅后悬浮数据环、姜金胸带、六角青色胸核、指挥杆。

### 智能之母 — `mother-mind.png`（非人形锚点）

- **Role**: 兽星的统治者。不是机器人，是一整颗星球的运算核心；巡逻机器人与机械军团都是它的手脚。
- **Form**: 山岳级球体，坐落在地底空穴里，由暗钢支塔与电弧夹钳托住；赤道一圈完整检修栈桥与吊臂。
- **Hull**: 枪灰铆接装甲板拼成球壳，散热百叶、管束、线缆桥架密布；若干板块画危险黄斜带；接缝渗锈，下半球挂着油烟与泥痕。
- **Eyes**: 球面密集成千上万枚单缝冷青视镜——与巡逻机器人同一套视觉语言，像复眼一样排布；正中央一道巨大的横向主视镜，狭长、无嘴、无人脸。
- **Feeding**: 球体底部一束粗如隧道的脐带主干线垂落，插进下方发橙光的能源井；井口有热浪与瀑布状冷却水。
- **Scale cues**: 吊装平台、索桥吊篮、栈桥上蚂蚁般的机器单位——用来衬托球体之大。
- **Palette**: 枪灰、油黑、危险黄、冷青、锈橙、炉光橙。
- **Never change**: 球形 + 密集单缝冷青视镜 + 中央一道横向主视镜 + 危险黄斜带 + 底部脐带管线接入发光能源井。
- Note: 本稿是 1536x1024 横版场景锚点，不是角色定妆版式；作页面参考时说明「这是智能之母的外形与尺度基准」。它被破坏时按顺序失能：先能源井（P40，视镜成片转暗）→ 后主视镜与干线缆（P42，全灭，只剩应急红灯）。

### 智人先锋舰队 / 生化人 — 场景设定（暂无锚点图）

P67–P71 的成图是它目前的视觉依据。舰队与生化人共用智人的配色语言：骨白、石墨灰、姜金、一点青。

- **舰体**：几何切面的骨白 + 石墨拼板，接缝极细，缝里透青；舰身有少量姜金饰带。矛头阵编队，最前一艘是母舰。整体必须「干净到像医疗器械」，与兽星的废铁形成对照。
- **舰内**：骨白与石墨的无缝走廊、几何拱顶、嵌在墙里的青色灯条、六角青色核心柱；没有生活痕迹。
- **武器**：笔直、等距、细如针的青白光柱，齐射时不乱阵型。破坏力极大，但画面上不出现爆炎与火球——精确，不咆哮。
- **生化人**：在舰队中扮演智人的量产仿制品。外形与智人定妆稿一致（光头无眉、石墨耳甲、骨白石墨紧身甲、姜金胸带、六角青核），但更「塑料」：同样的脸、同样的姿态。开胸后没有骨与血，只有散热肋片、六角电芯、冷青冷却液和一块空白刻号牌。存放舱里成排立在接口格里休眠，等指令。P72 起被黑熊整编进兽人队伍，仍穿骨白甲，作为辅助单位随队行动。
- **规矩**：真正的智人一个都不出现。舰队里全是仿制品——这是第二话的钩子，不要在本话任何画面里给出真智人。

### 量子穿越门 — 道具设定（暂无锚点图）

P73–P74 的成图是它目前的视觉依据。兽星自己造的东西，不是智人的成品科技。

- **形态**：竖立的大环，至少三层楼高。环体是缴获的骨白舰板焊在废铁架上：焊缝、刮痕、褪色危险黄斜带、垂到地面的缆线与冷却管。环缘一圈细青弧光。
- **开启**：环心裂成几何碎片，一片片向外翻卷旋转，碎片后面是青白硬光。没有风，没有声音。
- **刻意重复**：碎片外翻的动作与 P54 莲花被从内部掰开的几何语言一致——不解释，让读者自己认。
- **Palette**：骨白、枪灰、危险黄、冷青；只有环心的光是「无菌」的。

### 黑风星 — 场景设定（暂无锚点图）

- **行星**：被黑色风暴带整圈裹住的气体星，风从下往上刮；风暴里夹着碎屑与黑色的絮状物。
- **补给港**：挂在浮空平台上的集市，篷布、吊灯、缆索与抓钩；来的都是过路的船，没人问来路。
- **黑风怪的巢**：风暴中央的废舰拼接平台，斗篷似的黑气从平台边缘往下淌。细节以 P83–P85 成图为准。
- **规矩**：这里的「风」会吹灭火——不是象征，是物理。红孩儿的三昧真火在这里第一次被压住。
- **P86–P90 现状**：哪吒循火线追到；两人在霸主台上从要人打到三头六臂对风轮，甲板被撕开、黑风从裂缝往上喷。红孩儿的破法不靠蛮力：**火不往外烧，往金属里面烧**——风能吹灭火苗，吹不到链子内部。这条可以作为往后在黑风星用火的通用解法。
- **P91–P95 现状**：红孩儿脱锁后先打哪吒，要抢「跟黑风怪的对决」，三方各打各的；黑风怪全程不急，借风把两人互相扔。最后他建起风墙、拆掉整块平台，两人坠进黑里。**关系定调**：哪吒与红孩儿不是队友，只是刚好背对背；互相掩护过一次，谁也没承认。
- **P96–P100 现状**：平台下面是一条竖井风道，井底是没上锁的星核。黑风怪把四叶轮当进气口，把星核整根吸走——**星球从此开始崩解**，所有地面都变成碎的、翘的、浮的。破法沿用 P90 的逻辑但升级：**风往里吸的时候，火跟着风进得去**。红孩儿在正面把火柱打进轮口，哪吒用长枪卡住面具与头盔的接缝，两下同时成立，面具裂开、螺旋倒转，黑风怪被自己吸进去的东西抽空而死。结局：**黑风星彻底瓦解**，两人砍断锚链，开走当初被扣的那条红帆小船。谁也没说「合作」两个字。
- **后续可用的物理规则**：① 风只在星球有星核时往上吹，星核被吸走后风是乱的、会倒灌；② 黑风怪的风轮既是武器也是进食器官，张嘴时风力向内；③ 他的铁面是铆接的，接缝是唯一弱点；④ 星球没了之后，这条船是两人唯一的载具。

### 红帆小船 — 第二话载具（P100–P105 成图为依据）

- **船**：铆接铁壳的小型补给船，单桅，补丁红帆，甲板上散着木箱、盘绳与破帆布；船尾一根舵柄。不是战舰，也没有武器。
- **环境**：黑风星碎成缓慢翻滚的碎星带，远处是被拆开的星球外壳，裂缝里还渗着青光；没有水面、没有陆地，船悬在虚空里。
- **航向**：P105 起，远处一条极细的玉白色光丝横过天空，是观音给的指向。赶路段落都沿它走；它不解释原理。
- **不可破坏**：第二话前期这条船是两人唯一的立足点，决斗再狠也不许把它打沉（P102 一度被掀侧，仅此而已）。

### 五彩石星 — 场景设定（P10–P13、P75–P77）

- **行星**：巨大的五色条纹行星，条带为青、赤、黄、白、黑；外圈悬着碎石环。
- **地表**：五色结晶平原，踩上去不响；地平线上是「织天巨门」——织机与天门缝合而成的巨大残骸。
- **殿内**：石柱高不见顶，头顶横着古老的织机横梁；尽头基座还亮着，座位空着。
- **封印**：外层是五层六角壳，颜色对应五色石，一层咬着一层。量子门切开的地方，壳片向外翻卷剥离。P72 的全息图在成图上偏红、金、绿、蓝、紫，后续统一按五色石的五色处理。
- **现状**：女娲在此洗石后离去；悟空的船与法力被关掉，人被困在星上。P78–P80：悟空与八戒重逢，女娲那句「你是哪个猴子，在找哪个师傅」被仿制品解读为多元宇宙的坐标问题（每个宇宙都有一个不同的他）；悟空随队经量子门返回兽星，门在身后熄灭，只留下空台与掉落的碎片。

### 无尘星 — 场景设定（P48–P52、P106–P110 成图为依据）

星球名为暂定，第二话定稿。P48–P52 与 P106–P110 的成图就是它目前的视觉依据，画新页时以这几页为准。

**它是一颗活着的、有智能的星球。** 整颗星是一个生命体，石头是它的细胞、手脚和字。它没有声音、没有语言、没有名字，也不说话——它用形状、接触和位置说话。它不攻击人；它的危险只在于太大、太慢、不懂人。

- **地貌**：未被开垦的原始森林，没有任何建筑、道路、机械。唯一的「结构」是树——单根光滑树干如石柱，笔直插入云层以上，板根撑开像废墟的墙。
- **反常点**：干净。水清到能数石子，没有腐木、枯叶、虫、霉斑。这份「不脏」是伏笔，不要用发光或符号去解释。
- **洞口**：开在树根与白石堆成的小丘侧面，拱形异常光滑规整，几乎是几何的，洞缘爬满细密的六边形纹——要看起来像石头自己长成的，不是人造门框。
- **活石**：打磨过的带纹石、半透石、切成规整多面体的石；离地悬浮、互相滑动换位、组合成形状，但**彼此从不碰撞**。组合出的造型（四足兽、拱、螺旋、鸟、球）允许比例错误并正在自我修正——它在模仿，不是在创造。
- **Palette**：墨线、暖灰纸、深青、藏红（唐僧袍）、一点冷青发光（锡杖与铲刃）；晨景可加一层淡金（P110），但不许变成暖色童话。

#### 语言四层（P106–P110 定稿，后续照此写）

1. **形状 = 复读**。它只会复制它见过的形状，比例可以对，理解为零。P106：抬手 → 巨手；指方向 → 石头散开（它没有「那边」这个词）；落回地面 → 两尊无脸石人。
2. **边界 = 不碰**。石头之间永远隔一线空气，像细胞不融合。P107：唐僧双手按到指尖发白也合不上，冷青只在缝里。它把空地退出来，是尊重，不是害怕。
3. **词 = 接触**。P108：唐僧借沙僧的手示范「碰」，星球第一次让石头相扣，整片空地拼成一只摊开的手。**这是它学会的第一个词，此前所有「说话」都不算。**
4. **语法 = 位置**。P109–P110：它把记忆搬出来（逃生舱、白骨人石像）；唐僧在尘上画星图，把石头放在一个点上，它就把一条石子路铺向天边。位置就是句子。

**记忆**：它记得来过的东西——P109 的逃生舱是唐僧自己的，半被石头包成壳；成排的无脸石像是它对白骨人的粗抄（无脸、无眉、无发，头顶只有串珠环，那是它复读唐僧念珠的结果，**不是**白骨人的数据环）。石像不带情绪，也不攻击。

**能力边界**：石头只在星球表面活动，不进洞穴内部；冷青只在接缝或回应时亮，不是能量武器；它能数出地表上的生命体（P110 的「两个」），也能判断温度，但不懂名字、时间与因果。别让它突然全知。

## Using the anchors

`thumbs/<slug>.jpg` are 4:5 web crops of the right-hand portrait on each sheet, used by the reading site. They are derived, never canon — regenerate them if a sheet changes.

1. **Same character, new page**: pass the matching sheet to ImageGen as a reference image and state "the first image is the identity and costume reference; keep face, hair, silhouette, costume and palette unchanged". Restate the locked art direction.
2. **Multi-character panel**: one reference per character, labeled by order. Keep each character's never-change list in the prompt.
3. **New characters**: generate a sheet in the same layout, add them here, then they become canon.
4. **One pass per asset.** No regeneration loops. If the result deviates, record the deviation in the page notes and move on.
