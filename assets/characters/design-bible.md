# Character Design Bible

This file is the canon. Every future page, cover or promo image must match the sheets in this folder. When a page and this file disagree, this file wins.

## Locked art direction

Reuse this block verbatim in every image prompt:

> professional Japanese shonen sci-fi manga illustration, crisp black ink linework, cel shading with screentone dot patterns, limited bold palette, 1990s-2000s manga poster polish, pale warm-gray paper, halftone starfield

Reference-sheet layout (for new characters only): vertical sheet, full-body three-quarter view on the left, large head-and-shoulders portrait on the right, thin ink border frame, faint halftone starfield background, no text or labels.

## Using the anchors

1. **Same character, new page**: pass the matching sheet to ImageGen as a reference image and state "the first image is the identity and costume reference; keep face, hair, silhouette, costume and palette unchanged". Restate the locked art direction.
2. **Multi-character panel**: one reference per character, labeled by order. Keep each character's never-change list in the prompt.
3. **New characters**: generate a sheet in the same layout, add them here, then they become canon.
4. **One pass per asset.** No regeneration loops. If the result deviates, record the deviation in the page notes and move on.
